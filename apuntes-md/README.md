# Bandeja de entrada de apuntes

Coloca aquí los archivos Markdown (`.md`) que se convertirán a LaTeX.

Convención sugerida:

- `01-tema.md`, `02-tema.md`, etc. para conservar el orden.
- Usa encabezados `#`, `##` y `###` con una jerarquía consistente.
- Encierra las fórmulas entre `$...$` o `$$...$$`.
- Usa bloques de código cercados e indica el lenguaje cuando corresponda.
- Guarda las imágenes en `apuntes-md/imagenes/` y enlázalas con rutas relativas.
- Si una sección es una actividad, inicia el encabezado con `Actividad:`.

No es necesario que el Markdown esté perfecto: durante la conversión se
normalizarán tablas, fórmulas, imágenes, actividades y diagramas.
